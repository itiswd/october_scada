# october_scada

مشروع October SCADA هو تطبيق Flutter متعدد المنصات لمراقبة والتحكم في محطات ضخ المياه (7 محطات) في الوقت الفعلي. يستخدم بروتوكول MQTT للاتصال بأنظمة التحكم الصناعية (PLC) لعرض بيانات المضخات، الصمامات، الخزانات، مصادر الطاقة، والمستشعرات بشكل مرئي وتفاعلي.
